# E-Commerce Sales Analysis

End-to-end analysis of e-commerce sales data using **SQL**, **Python**, and **Power BI**.

## Project Overview
This project analyzes over **138,000 transactions** to understand revenue performance, customer behavior, channel effectiveness, and profitability.

**Business Questions Answered:**
- Which regions and customer segments generate the most revenue?
- Which sales and marketing channels perform best?
- How do discounts impact profit margins?
- What is the contribution of repeat vs new customers?

## Key Insights
- **Total Revenue:** ₹177.13 Cr  
- **Total Profit:** ₹76.15 Cr  
- **Average Profit Margin:** 45.07%  
- **South** region generated the highest revenue  
- **Consumer** segment was the largest contributor  
- **Mobile App** was the top sales channel  
- **Organic Search** performed best among marketing channels  
- Almost all revenue came from **Repeat customers**  
- High discounts significantly reduced profit margins  

## Business Recommendations
- Focus on acquiring more new customers
- Invest more in Mobile App and Website
- Scale Organic Search and Google Ads
- Improve performance in the North region
- Optimize discount strategy to protect margins
- Strengthen retention programs for the Consumer segment

## Tools Used
